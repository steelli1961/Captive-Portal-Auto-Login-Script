# Αυτόματη σύνδεση σε pfSense Captive Portal

Αυτό το script χρησιμοποιεί το Selenium για να συνδέεται σε ένα pfSense captive portal, το οποίο έχετε δικαίωμα να χρησιμοποιείτε. Υποστηρίζει τα τυπικά πεδία του pfSense (`auth_user` και `auth_pass`), καθώς και τα γενικά πεδία `username` και `password`.

## Windows 11: αρχική εγκατάσταση

Χρειάζεστε έναν υπολογιστή με Windows 11 συνδεδεμένο στο δίκτυο του pfSense, Python 3.9 ή νεότερη και Google Chrome. Δεν χρειάζεται να κατεβάσετε ξεχωριστά το ChromeDriver. Το Selenium συνήθως κατεβάζει αυτόματα την κατάλληλη έκδοση.

### 1. Εγκατάσταση Python

1. Ανοίξτε τη σελίδα [python.org/downloads](https://www.python.org/downloads/) στον Chrome.
2. Κατεβάστε τον τρέχοντα installer για Windows.
3. Εκτελέστε τον installer.
4. Στην πρώτη οθόνη του installer επιλέξτε **Add Python to PATH** και μετά **Install Now**.
5. Κλείστε και ανοίξτε ξανά όποια παράθυρα PowerShell ήταν ήδη ανοιχτά.

Για να ελέγξετε την Python, ανοίξτε το μενού Έναρξη των Windows, πληκτρολογήστε **PowerShell**, ανοίξτε το και εκτελέστε:

```powershell
python --version
```

Θα πρέπει να εμφανιστεί μια έκδοση Python, για παράδειγμα `Python 3.12.0`. Αν ανοίξει το Microsoft Store αντί για την Python, εγκαταστήστε ξανά την Python και βεβαιωθείτε ότι επιλέξατε **Add Python to PATH**.

### 2. Άνοιγμα του φακέλου του project

Κατεβάστε ή αντιγράψτε αυτό το project σε έναν φάκελο, για παράδειγμα:

`C:\Users\YourName\Captive-Portal-Auto-Login-Script`

Στον File Explorer ανοίξτε αυτόν τον φάκελο. Κάντε κλικ στη γραμμή διεύθυνσης, πληκτρολογήστε `powershell` και πατήστε **Enter**. Το PowerShell θα ανοίξει στον σωστό φάκελο.

### 3. Εγκατάσταση Selenium

Στο ίδιο παράθυρο PowerShell εκτελέστε:

```powershell
python -m pip install selenium
```

Περιμένετε να ολοκληρωθεί η εντολή. Την πρώτη φορά μπορεί να χρειαστεί σύνδεση στο Internet, ώστε το Selenium να κατεβάσει το κατάλληλο ChromeDriver.

### 4. Σύνδεση στο captive portal

Συνδεθείτε στο δίκτυο μέσω Ethernet ή Wi-Fi. Ανοίξτε τον Chrome και επισκεφθείτε τη διεύθυνση `http://neverssl.com`. Το δίκτυο θα πρέπει να σας ανακατευθύνει στη σελίδα σύνδεσης του pfSense. Αντιγράψτε ολόκληρη τη διεύθυνση από τη γραμμή διεύθυνσης του Chrome, συμπεριλαμβανομένων των `http://` ή `https://` και τυχόν αριθμού θύρας.

Μην χρησιμοποιήσετε τη συνηθισμένη διεύθυνση διαχείρισης του pfSense, εκτός αν αυτή είναι πράγματι η διεύθυνση του captive portal.

### 5. Εισαγωγή ρυθμίσεων και εκτέλεση

Στο ίδιο παράθυρο PowerShell αντικαταστήστε τις ενδεικτικές τιμές παρακάτω με την πραγματική διεύθυνση του portal, το όνομα χρήστη και τον κωδικό πρόσβασης:

```powershell
$env:PFSENSE_URL = "https://portal.example.com:8000/"
$env:PFSENSE_USERNAME = "your_username"
$env:PFSENSE_PASSWORD = "your_password"
$env:PFSENSE_HEADLESS = "false"
python .\main.py
```

Χρησιμοποιήστε `$env:PFSENSE_HEADLESS = "false"` για την πρώτη δοκιμή, ώστε να βλέπετε το παράθυρο του Chrome. Αφού λειτουργήσει η σύνδεση, κλείστε το script και εκτελέστε:

```powershell
$env:PFSENSE_HEADLESS = "true"
python .\main.py
```

Οι ρυθμίσεις ισχύουν μόνο για το τρέχον παράθυρο PowerShell. Αυτό γίνεται σκόπιμα: ο κωδικός πρόσβασης δεν αποθηκεύεται μέσα στο script. Όταν ανοίξετε νέο παράθυρο PowerShell, θα πρέπει να ορίσετε ξανά τις μεταβλητές.

Το script εμφανίζει το αποτέλεσμα. Επιστρέφει κωδικό `0` σε περίπτωση επιτυχίας, `1` μετά από αποτυχημένες προσπάθειες σύνδεσης ή `2` όταν λείπει κάποια απαραίτητη ρύθμιση.

### 6. Επόμενες εκτελέσεις

Ανοίξτε ξανά το PowerShell στον φάκελο του project και επαναλάβετε τις τέσσερις εντολές των μεταβλητών περιβάλλοντος και μετά την εντολή `python .\main.py`. Ο υπολογιστής πρέπει να είναι συνδεδεμένος στο ίδιο εξουσιοδοτημένο δίκτυο.

Το Selenium συνήθως βρίσκει αυτόματα τον κατάλληλο ChromeDriver. Ορίστε το `CHROMEDRIVER_PATH` μόνο αν θέλετε να χρησιμοποιήσετε συγκεκριμένο αρχείο ChromeDriver.

## Σύνδεση δικτύου

Το script είναι ανεξάρτητο από τον τύπο σύνδεσης. Χρησιμοποιεί τη συνηθισμένη διαδρομή δικτύου του λειτουργικού συστήματος, επομένως λειτουργεί μέσω Ethernet, Wi-Fi ή USB network adapter χωρίς αλλαγές στον κώδικα Python. Ο υπολογιστής που εκτελεί το script πρέπει ήδη να έχει πάρει IP από το δίκτυο του pfSense και να υπόκειται στο captive portal αυτού του δικτύου.

Αν είναι συνδεδεμένα ταυτόχρονα Ethernet και Wi-Fi, τα Windows επιλέγουν μία σύνδεση με βάση τα route metrics. Η σύνδεση θα εφαρμοστεί στο interface και στην ταυτότητα client που χρησιμοποιούνται από αυτή τη διαδρομή. Για την πρώτη δοκιμή αποσυνδέστε τον adapter που δεν θέλετε να χρησιμοποιήσετε. Το script δεν δημιουργεί τη σύνδεση δικτύου και δεν επιλέγει adapter.

## Εγκατάσταση σε Linux

Σε Linux εγκαταστήστε την Python και το Selenium, ορίστε τις ίδιες απαραίτητες μεταβλητές περιβάλλοντος και εκτελέστε το script:

```bash
python3 -m pip install selenium
export PFSENSE_URL='https://portal.example.com:8000/'
export PFSENSE_USERNAME='your_username'
export PFSENSE_PASSWORD='your_password'
export PFSENSE_HEADLESS=true
python3 main.py
```

Μην αποθηκεύετε τα στοιχεία σύνδεσης στο Git και μην τα γράφετε απευθείας μέσα στο αρχείο του script.

## Προαιρετικές ρυθμίσεις

| Μεταβλητή | Χρήση | Προεπιλογή |
| --- | --- | --- |
| `PFSENSE_HEADLESS` | Εκτέλεση του Chrome χωρίς ορατό παράθυρο | `true` |
| `PFSENSE_TIMEOUT` | Δευτερόλεπτα αναμονής για τα στοιχεία του portal | `20` |
| `CHROME_PATH` | Πλήρης διαδρομή προς Chrome/Chromium | Προεπιλογή Selenium |
| `CHROMEDRIVER_PATH` | Πλήρης διαδρομή προς εκτελέσιμο ChromeDriver | Selenium Manager |

## Αντιμετώπιση προβλημάτων

- **Το `python` δεν αναγνωρίζεται:** Εγκαταστήστε ξανά την Python, επιλέξτε **Add Python to PATH** και ανοίξτε ξανά το PowerShell.
- **Το Selenium δεν μπορεί να εκκινήσει τον Chrome:** Βεβαιωθείτε ότι είναι εγκατεστημένος ο Google Chrome και κλείστε άλλα παράθυρα δοκιμών. Την πρώτη φορά το Selenium μπορεί να χρειαστεί Internet για να κατεβάσει το ChromeDriver.
- **Το script αναφέρει ότι λείπει κάποια ρύθμιση:** Ορίστε τα `PFSENSE_URL`, `PFSENSE_USERNAME` και `PFSENSE_PASSWORD` στο ίδιο παράθυρο PowerShell όπου εκτελείτε το script.
- **Δεν εμφανίζεται η σελίδα σύνδεσης:** Συνδεθείτε στο δίκτυο του pfSense και επισκεφθείτε χειροκίνητα το `http://neverssl.com`. Χρησιμοποιήστε τη διεύθυνση στην οποία ανακατευθύνεστε ως `PFSENSE_URL`.
- **Η σύνδεση αποτυγχάνει:** Ορίστε το `PFSENSE_HEADLESS` σε `false`, εκτελέστε ξανά το script και ελέγξτε αν η σελίδα χρησιμοποιεί διαφορετική φόρμα ή εμφανίζει μήνυμα λανθασμένων στοιχείων.
- **Είναι συνδεδεμένα Ethernet και Wi-Fi:** Τα Windows επιλέγουν μία σύνδεση με βάση τα route metrics. Για την πρώτη δοκιμή αποσυνδέστε τον adapter που δεν θέλετε να χρησιμοποιήσετε.

Το script θεωρεί επιτυχημένη τη σύνδεση όταν εξαφανιστεί η φόρμα σύνδεσης. Αν το δικό σας portal κρατά τη φόρμα ορατή μετά από επιτυχημένη σύνδεση, θα χρειαστεί προσαρμογή του ελέγχου επιτυχίας.

## Προγραμματισμένη εκτέλεση

Εκτελείτε το script μόνο σε υπολογιστή που είναι ήδη συνδεδεμένος στο εξουσιοδοτημένο δίκτυο. Για προγραμματισμένη εκτέλεση στα Windows μπορείτε να χρησιμοποιήσετε το **Task Scheduler**. Δημιουργήστε μια εργασία που εκτελεί την Python και ορίστε τις μεταβλητές περιβάλλοντος στο περιβάλλον της εργασίας ή χρησιμοποιήστε ένα προστατευμένο αρχείο ρυθμίσεων.

Σε Linux, ένα παράδειγμα cron είναι:

```cron
*/30 * * * * . /path/to/pfsense.env && /usr/bin/python3 /path/to/main.py >> /path/to/captive-portal.log 2>&1
```

Το portal πρέπει να επιτρέπει αυτοματοποιημένη πρόσβαση και τα στοιχεία σύνδεσης πρέπει να χρησιμοποιούνται σύμφωνα με τους όρους του διαχειριστή του δικτύου.
